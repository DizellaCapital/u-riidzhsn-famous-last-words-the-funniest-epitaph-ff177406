make.fun bounty entry: the funniest famous last words as a single tombstone
epitaph, at most 150 characters. The line is the whole entry.

## The line

> They charged by the letter, so this is all I could afford.

58 characters. The dead speak from their own stone — and the stone itself is
the joke. An epitaph is supposed to be grand and carved to last; this one is
short because the stonecutter charged by the letter. The brevity that makes it
look carved in stone is also the punchline: the speaker could not afford a
longer goodbye. No stage directions, no explanation, one short line, exactly
as a tombstone would carry it.

## Run it

```sh
python3 main.py  # writes entry.txt to $MAKEFUN_OUTPUT_DIR (fallback /output)
```

`main.py` (stdlib only) checks the line is a single line of 1–150 characters,
writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), then reads
the file back and refuses to finish unless the bytes on disk are exactly the
line that was written.
